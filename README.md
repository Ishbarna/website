# Ishbarna's security blog

A dependency-free static security blog with a clear, flat structure.

## Structure

```text
/
├── index.html
├── style.css
├── script.js
└── posts/
    ├── tryhackme/
    ├── picoctf/
    └── defensive-security/
```

All pages use the root `style.css` and `script.js`. Copy a post from the closest category to add a new article, then add its card to `index.html`.
